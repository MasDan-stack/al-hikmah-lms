# AL-HIKMAH Website

Website resmi **AL-HIKMAH** — Menemani perjalanan anak usia 10–15 tahun untuk mengenal, mencintai, dan menghidupkan nilai-nilai Al-Qur'an dalam kehidupan.

## 🚀 Teknologi

- HTML5
- CSS3 (Custom Properties, Flexbox, Grid)
- JavaScript (Vanilla)
- Bootstrap 5.3
- Bootstrap Icons
- Poppins Font
